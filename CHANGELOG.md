# Lookup

## v0.3.0

- Bag items: Shift+Enter uses the item (food, potions, quest items) or puts on gear.
- A typed command over 255 characters now says it is too long. Before, Enter did nothing and the text was still remembered.
- Long searches scroll in the box. Before, the text ran past the right edge.
- Addon key bindings that act when you release the key now get the release when they run from Lookup.

## v0.2.0

- New first-time setup: a key card opens where the search box opens. Press the key it shows to use it, or press another combo to pick that one instead. In v0.1.0 the welcome window could close by itself at login.
- Your Lookup key now closes the box too.
- Minimap tracking: each tracking type (Flight Master, Mailbox, Repair, ...) is an on/off row.
- Stopwatch, Clock and Edit Mode rows.
- The Currency row says when a character has no currencies yet, instead of doing nothing.

## v0.1.0

The first release.

- A search box for panels and tabs, settings, key bindings, zones, quests, mounts, pets and toys, spells, macros, bag items, currencies, reputations, Legacy Challenges, slash commands, addon launchers, friends and guild members.
- Spells cast on Enter. Shift+Enter opens the spellbook on the spell's tab.
- Command mode: type `/` to list commands, then press Space to add text after one.
- On/off settings change in place.
- A calculator.
- Lookup remembers your picks and the text you add to commands.
- A welcome window on first login suggests a free key, and the empty box shows example searches until you have picked a few rows.
